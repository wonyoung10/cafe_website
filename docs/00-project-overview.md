# 00. 프로젝트 개요

## 1. 프로젝트 한 줄 요약

임시 브랜드 **'하루의 잎'** 카페의 브랜드 철학을 전달하는 **React + Vite + TypeScript + React Router DOM** 기반 소개 웹사이트. Three.js(React Three Fiber)로 만든 **인터랙티브 3D 가상 매장**을 핵심 기술 요소로 포함한다.

## 2. 과제의 목적

| 구분 | 내용 |
|---|---|
| 성격 | 대학교 웹 프로그래밍 과제 (비상업) |
| 학습 목표 1 | 컴포넌트 기반 SPA 설계 — React, TypeScript 타입 설계, 데이터/화면 분리 |
| 학습 목표 2 | 클라이언트 라우팅 — React Router DOM의 `BrowserRouter`, `Routes`, `Route`, `NavLink`, 404, 스크롤 처리, Lazy Loading |
| 학습 목표 3 | 웹 3D — Three.js / React Three Fiber / Drei로 탐색 가능한 실내 공간 구현 |
| 학습 목표 4 | 반응형 UI·접근성 — Tailwind CSS, 모바일 터치 대응 |
| 학습 목표 5 | 협업 프로세스 — 기획 문서, 로컬 Git 브랜치/Worktree, 멀티 에이전트 분업, 테스트 자동화 |

## 3. 핵심 기능

1. **홈(`/`)** — 히어로, 메인 카피, 브랜드 철학, 대표 메뉴 미리보기, 3D 매장 미리보기, 위치 요약
2. **메뉴소개(`/menu`)** — 23개 메뉴, 4개 카테고리 필터, 카드 UI, HOT/ICE 표시, 판매가 표시
3. **매장(`/store`)** — Three.js 가상 카페 3D 뷰어 (둘러보기 / 실내 탐색 모드, 핫스팟, 충돌 처리, 로딩, WebGL 대체 UI)
4. **오시는 길(`/location`)** — 주소, 지도, 주소 복사, 네이버지도·카카오맵 길찾기 링크
5. **공통** — 헤더(메뉴소개·매장·오시는 길), 로고→홈, 활성 메뉴 표시, 푸터, 404 페이지

## 4. 개발 범위

### 포함
- 정적 SPA 프론트엔드. 회원·구매·리뷰는 Supabase를 쓴다 (2026-11-25 사용자 요청, 13 문서·ADR-008)
- 생성형 이미지 에셋 (Codex CLI 이미지 생성 기능 활용)
- 절차적(Procedural) 3D 모델링 — 외부 3D 모델 파일 없이 코드로 가구·공간 구성
- 단위 테스트(Vitest), E2E 테스트(Playwright)

### 제외 (과제 범위 밖, `13. 범위 제한` 준수)
- 실제 결제 (회원가입·로그인·장바구니·모의 결제·리뷰는 2026-11-25 사용자 요청으로 범위에 포함, 메뉴 가격은 2026-11-17 사용자 요청으로 표시 범위에 포함)
- 매출·수익·예산·사업화·마케팅 퍼널 분석
- 관리자 시스템, 자체 백엔드 서버
- 확인되지 않은 매장 정보(대중교통, 주차, 운영시간, 전화번호)

## 5. 기술 활용 목표

| 기술 | 활용 목표 |
|---|---|
| React 19 | 함수형 컴포넌트, Hooks, `lazy`/`Suspense` |
| Vite | 개발 서버, 코드 스플리팅(3D 청크 분리), 프로덕션 빌드 |
| TypeScript | `strict` 모드, 도메인 타입(`MenuItem`, `Hotspot` 등), `any` 금지 |
| React Router DOM | 선언적 라우트, `NavLink` 활성 표시, 404, 스크롤 복원 |
| Tailwind CSS v4 | `@theme` 디자인 토큰, 반응형 유틸리티 |
| Three.js + R3F + Drei | 3D 공간, 카메라 컨트롤, 핫스팟(`Html`), 로딩(`useProgress`) |
| Motion | 절제된 진입·전환 애니메이션, `prefers-reduced-motion` 존중 |
| Lucide React | 일관된 라인 아이콘 |
| Vitest + Testing Library | 라우팅·필터링·유틸 단위 테스트 |
| Playwright | 실제 브라우저 E2E (라우팅, 새로고침, 모바일, 3D 캔버스) |
