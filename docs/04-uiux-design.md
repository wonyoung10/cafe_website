# 04. UI/UX 설계

## 1. 공통 레이아웃

```text
┌──────────────────────────────────────────────────────────┐
│ [스킵 링크: 본문으로 건너뛰기]                              │
│ HEADER (sticky, 반투명 아이보리 + backdrop-blur)            │
│  🍃 하루의 잎              메뉴소개   매장   오시는 길        │
├──────────────────────────────────────────────────────────┤
│ <main id="main"> … 페이지 … </main>                        │
├──────────────────────────────────────────────────────────┤
│ FOOTER (포레스트 그린 배경, 아이보리 텍스트)                 │
│  로고 · 철학 한 줄 · 주소 · 내비 · "대학교 웹 프로그래밍 과제" │
└──────────────────────────────────────────────────────────┘
```

- 헤더 높이: 모바일 64px, 데스크톱 72px. 스크롤 시 하단 보더(`line`) 표시.
- 활성 메뉴: 포레스트 그린 텍스트 + 하단 2px 잎 색(세이지) 밑줄 + `aria-current="page"`.
- 모바일(<768px): 햄버거 버튼(`aria-expanded`, `aria-controls`) → 상단에서 내려오는 패널. ESC·바깥 클릭·라우트 변경 시 닫힘. 열린 동안 body 스크롤 잠금.
- `/store`는 3D 뷰어 집중을 위해 푸터를 유지하되 뷰어 높이를 `calc(100svh - header)`로 둔다.

## 2. 페이지별 와이어프레임

### 2.1 홈 `/`

데스크톱 (≥1024px)
```text
┌───────────────────────────────┬──────────────────────────┐
│ 오늘의 작은 쉼 (eyebrow)       │                          │
│ 당신의 하루에,                 │     [히어로 이미지]       │
│ 잎사귀 하나.  (h1, 고운바탕)   │   창가 원목 테이블 위      │
│ 한 잔의 커피가 오늘의 작은 쉼이 │   라떼와 잎 그림자         │
│ 되기를.                        │   (rounded-[2rem])        │
│ [메뉴 보기] [매장 둘러보기 →]   │                          │
└───────────────────────────────┴──────────────────────────┘
── 브랜드 철학 ──────────────────────────────────────────────
  " 나무에 잎사귀가 하나씩 더해지듯 … "  (큰 인용, 중앙)
  [🍃 자연의 재료] [☕ 정성의 한 잔] [🌿 머무는 쉼]  3열 카드
── 대표 메뉴 ───────────────────────── [전체 메뉴 보기 →] ──
  [카드][카드][카드][카드]   (4열)
── 3D 매장 미리보기 (배경 cream) ────────────────────────────
  좌: 설명 + [매장 들어가기]   우: 16:10 미니 3D 캔버스(자동 회전)
── 위치 요약 ───────────────────────────────────────────────
  📍 경기도 안양시 동안구 경수대로 940   [오시는 길 →]
```

모바일 (<768px): 모든 섹션 1열 스택. 히어로 이미지가 카피 아래로. 대표 메뉴는 2열 그리드. 3D 미리보기는 4:3.

### 2.2 메뉴소개 `/menu`

```text
메뉴소개 (h1)  — 오늘의 잎 한 장을 고르세요.
[전체 23] [Coffee 8] [Non-Coffee 6] [Tea 4] [Dessert 5]  ← 가로 스크롤 가능한 pill 버튼(모바일)
┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│ 이미지  │ │        │ │        │ │        │   1:1 이미지 (aspect-square)
│ COFFEE │ │        │ │        │ │        │   카테고리 eyebrow
│ 아메리카노│ …                                이름 (h3)
│ 설명 2줄 │                                  설명 (line-clamp-2)
│ [HOT][ICE]                                 온도 배지
└────────┘
```
- 그리드: 1열(<640) → 2열(sm) → 3열(lg) → 4열(xl)
- 필터 전환 시 카드 레이아웃 애니메이션(Motion `layout`, reduced-motion 시 생략)
- 결과 개수 `aria-live="polite"`로 안내

#### 2.2.1 '읽는 메뉴' 재구성 (2026-11-16)

```text
메뉴소개 (h1) — 오늘의 잎 한 장을 고르세요.
┌──────────── 필터 막대 (헤더 아래 고정) ────────────────── 23개의 메뉴 ┐
│ [전체 23] [Coffee 8] [Non-Coffee 6] [Tea 4] [Dessert 5]               │
└───────────────────────────────────────────────────────────────────────┘
🍃                ┌───────── 대표 메뉴(lead) ─────────┐ ┌──────┐
커피 Coffee        │ [사진]      카페라떼               │ │ 카드 │
매일 아침 갓 볶은…  │             Café Latte · 설명      │ └──────┘
8가지              └────────────────────────────────────┘
(데스크톱에서 고정) [카드] [카드] [카드]
                   [카드] [카드] [카드]
────────────────── 헤어라인 ──────────────────
🍃 논커피 …        (다음 카테고리)
```
- '전체'는 카테고리 4개 섹션, 특정 카테고리는 해당 섹션 하나만. 모든 메뉴는 여전히 `article` 카드(개수·E2E 동일).
- 카테고리마다 대표 메뉴 1개(`MenuItem.lead`: 카페라떼·말차라떼·유자차·크루아상)를 큰 카드로 맨 앞에.
- 데스크톱 3열 격자에서 마지막 줄이 비지 않도록 대표 카드 모양을 자동 선택(`getLeadLayout`): 2칸×1줄(가로형) · 2칸×2줄(세로형) · 3칸×1줄(넓은 가로형).
- 필터 막대는 헤더 아래 고정. 목록 중간에서 필터를 바꾸면 새 목록의 처음으로 부드럽게 이동(reduced-motion이면 즉시).
- 섹션 안에서는 카드의 카테고리 라벨을 숨긴다(제목과 중복).

│                                              │ 공간 둘러보기  │
│              3D CANVAS                        │ • 커피 바      │
│      (핫스팟: 잎 모양 원형 마커 + 라벨)        │ • 에스프레소   │
│                                              │ • 창가 좌석    │
│  [조작 안내 칩: 드래그 회전 · 휠 줌 · …]       │ • 진열장 …     │

- 모바일: 사이드 목록 → 캔버스 아래 가로 스크롤 칩

## 3. 내비게이션 동작

| 동작 | 결과 |
|---|---|
| 헤더 링크 클릭 | 클라이언트 라우팅, 스크롤 최상단, 모바일 메뉴 닫힘 |
| 같은 경로 재클릭 | 스크롤 최상단으로 부드럽게 이동 |
| 뒤로/앞으로 | 라우터 히스토리 복원 |
| `/menu?category=…` | 필터 상태를 쿼리에서 복원 (잘못된 값은 '전체') |
| 해시 링크(`/#philosophy`) | 해당 섹션으로 스크롤 |

## 4. 애니메이션 & 인터랙션

| 대상 | 효과 | 시간/이징 |
|---|---|---|
| 섹션 진입 | opacity 0→1, y 24→0 (`whileInView`, once) | 0.7s, `[0.22, 1, 0.36, 1]` |
| 버튼 hover | 배경 톤 다운 + 화살표 x+4px | 0.2s |
| 카드 hover | 이미지 scale 1.03, 그림자 강화 | 0.4s |
| 필터 전환 | Motion `layout` + `AnimatePresence` | 0.35s |
| 3D 카메라 이동 | 핫스팟 선택 시 위치·타깃 보간(damp) | 약 1.2s |
| 철학 섹션 잎 | 스크롤에 따라 잎 아이콘 하나씩 채워짐 | 0.5s stagger |

원칙: **동시에 움직이는 요소는 최소화**, 무한 반복 애니메이션은 3D 미리보기 자동 회전(매우 느림)만 허용. `prefers-reduced-motion: reduce`에서는 Motion의 `MotionConfig reducedMotion="user"` 적용 + 3D 자동 회전 중지.

## 5. 접근성 고려 사항

- 랜드마크: `header`, `nav[aria-label="주 메뉴"]`, `main#main`, `footer`
- 스킵 링크 "본문으로 건너뛰기"
- 모든 인터랙티브 요소 `:focus-visible` 링 (포레스트 그린 2px + offset 2px)
- 이미지 `alt`: 메뉴는 "{메뉴명} 사진", 장식 이미지는 `alt=""`
- 색 대비: 본문 `ink(#2B2A26)` on `ivory(#FBF8F1)` ≈ 13:1, 포레스트 버튼 텍스트 아이보리 ≈ 9:1
- 3D: 캔버스에 `aria-label`, 핫스팟은 HTML 버튼(키보드 포커스 가능) + 캔버스 외부 핫스팟 목록 제공, 조작법 텍스트 제공
- 복사 완료/필터 결과는 `aria-live="polite"`
- 외부 링크: "(새 창)" 스크린리더 텍스트
- 터치 타겟 최소 44×44px
