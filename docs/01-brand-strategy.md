# 01. 브랜드 전략

> 브랜드명 **'하루의 잎'** 은 임시 이름이다. 이름·로고·카피는 `src/data/brand.ts` 와 `BrandLogo` 컴포넌트 한 곳에서만 관리하여 확정 시 한 번에 교체한다. (→ `decisions/ADR-004`)

## 1. 브랜드 철학

> "나무에 잎사귀가 하나씩 더해지듯, 한 잔의 커피가 누군가의 하루에 작은 잎사귀 하나가 되었으면 좋겠습니다."

커피를 마시는 짧은 순간이 누군가의 평범한 하루에 **작은 의미로 남기**를 바란다. 거창한 경험보다 **매일 조금씩 쌓이는 작은 쉼**을 지향한다.

## 2. 브랜드 스토리

한 그루의 나무는 하루아침에 자라지 않는다. 매일 아주 작은 잎 하나가 더해지고, 그 잎들이 모여 그늘이 되고 숲이 된다.

'하루의 잎'은 그 '잎 하나'가 되고 싶은 카페다. 출근길의 따뜻한 라떼, 오후의 차 한 잔, 친구와 나눈 스콘 한 조각. 그 순간들이 모여 누군가의 하루가 조금 더 푸르러지기를 바란다.

## 3. 브랜드 키워드 → 표현 전략

| 키워드 | 시각/경험 표현 |
|---|---|
| 나무와 잎사귀 | 잎사귀 심볼 로고, 섹션 구분 잎 아이콘, 3D 매장 내 다양한 식물 |
| 자연과 일상 | 자연광이 드는 창가 사진, 실제 일상 장면 같은 메뉴 이미지 |
| 따뜻함과 편안함 | 크림·아이보리 배경, 월넛 원목 톤, 따뜻한 색온도의 3D 조명 |
| 쉼과 여유 | 넉넉한 여백, 느린 이징(0.6~0.9s), 과하지 않은 모션 |
| 작은 행복과 성장 | 스크롤에 따라 잎이 하나씩 더해지는 '하루의 잎' 철학 섹션 |

## 4. 디자인 콘셉트

**"햇살 드는 오후의 원목 테이블"** — 자연주의 감성의 프리미엄 미니멀리즘.

- 장식은 줄이고, 소재감(원목·종이·잎)과 빛(부드러운 그림자)으로 분위기를 만든다.
- 흔한 카페 템플릿(커피콩 패턴, 갈색 일색, 과한 필기체)을 피한다.
- 세이지/포레스트 그린은 **포인트**로만, 바탕은 크림·아이보리.

## 5. 브랜드 메시지

| 용도 | 카피 |
|---|---|
| 메인 카피 | 당신의 하루에, 잎사귀 하나. |
| 서브 카피 | 한 잔의 커피가 오늘의 작은 쉼이 되기를. |
| 철학 섹션 | 나무에 잎사귀가 하나씩 더해지듯, 한 잔의 커피가 누군가의 하루에 작은 잎사귀 하나가 되었으면 좋겠습니다. |
| 메뉴 섹션 | 오늘의 잎 한 장을 고르세요. |
| 매장 섹션 | 햇살이 머무는 공간을 먼저 걸어보세요. |
| 위치 섹션 | 하루의 잎이 자라날 자리. |

톤앤매너: 존댓말, 짧은 문장, 과장 없는 표현. 느낌표·이모지 사용하지 않음.

## 6. 사용자에게 전달할 경험

1. **첫인상(홈)** — 3초 안에 "따뜻하고 차분한 자연주의 카페"임을 인지
2. **이해(철학)** — '하루에 잎 하나'라는 메시지를 시각적 은유로 기억
3. **탐색(메뉴)** — 가격 부담 없이 메뉴의 분위기·특징을 둘러봄
4. **체험(3D 매장)** — 가상 공간을 직접 걸으며 매장의 분위기를 미리 경험
5. **방문 의향(오시는 길)** — 주소 복사·길찾기로 실제 방문까지 연결
