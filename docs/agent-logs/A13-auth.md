# A13 회원가입·로그인·계정 메뉴

`feature/auth`의 기존 헤더와 라우터가 불러오는 인증 화면과 계정 메뉴를 구현했다. 인증 컨텍스트, 자격 증명 검증 함수, 복귀 경로 계약을 재사용했다.

## 요구사항과 테스트

| ID | 구현 및 확인 |
|---|---|
| AU-01 | 가입·로그인 후 요청한 내부 경로로 이동한다. 두 화면을 오가도 복귀 경로의 쿼리와 해시를 유지하고 외부 경로는 홈으로 보낸다. 이미 로그인한 회원도 같은 규칙을 따른다. 두 폼의 중복 제출, 틀린 아이디와 비밀번호에 대한 공통 오류, 데스크톱과 모바일 로그아웃을 테스트했다. |
| AU-02 | 가입 전에 아이디 길이를 설명한다. 키보드로 3자를 입력한 뒤 필드를 떠나면 오류가 연결되고, 네 번째 글자를 입력하면 해제된다. |
| AU-03 | 공통 비밀번호 검증 함수를 사용한다. 기호·한글·공백을 포함한 비밀번호는 가입 요청을 보내지 않고 비밀번호 칸에 오류를 연결한다. |
| AU-04 | 영문·숫자 4~20자와 대소문자 처리 규칙을 입력 전에 안내한다. 기존 아이디와 대소문자만 다르면 가입 시 아이디 칸으로 포커스를 보내고 로그인은 성공한다. 길이 상한은 기존 credentials 단위 테스트가 검사한다. |
| AU-05 | 5자 거부, 영문만 또는 숫자만으로 된 6자 허용, 확인 값 불일치, 원래 비밀번호 변경 후 확인 칸 재검증을 테스트했다. 두 비밀번호 칸의 표시 전환과 자동 완성 속성도 확인했다. |
| AU-06 | 메모리 API로 로그인한 뒤 앱을 언마운트하고 새 API와 인증 제공자로 다시 열었다. 두 인증 경로 모두 세션을 복원하고 목적지로 이동했다. 세션 조회 대기 중에는 폼과 비회원 링크가 나타나지 않는다. |
| AU-07 | 다른 곳에서 쓰는 비밀번호를 피하라는 안내를 비밀번호 입력의 접근 가능한 설명에 포함했다. 가입 성공 및 로그인 오류·재시도 흐름에서 비밀번호가 DOM 텍스트, URL, 콘솔 호출에 포함되지 않는지 확인했다. 가입 후 메모리 백엔드의 영속 저장소에도 평문이 없음을 검사했다. 운영 비밀번호 저장은 기존 Supabase Auth가 담당한다. |

계정 메뉴의 키보드 테스트는 Enter와 Space로 열기, Tab으로 주문 내역 이동, Escape로 닫고 트리거로 복귀하기를 확인한다. 바깥 클릭, 링크 선택, 로그아웃 시 포커스도 검사한다. 모바일 패널에는 회원의 아이디와 주문 내역·내 리뷰·로그아웃을 표시한다. 서비스 미설정 시 두 인증 화면은 공통 준비 안내를 표시한다.

## 검증 결과

- `npm run typecheck` 통과. TypeScript 오류 0건.
- `npm run lint` 통과. ESLint 오류·경고 0건.
- 전체 `npm run test` 최종 출력은 `Test Files 1 failed | 31 passed (32)`, `Tests 2 failed | 173 passed (175)`였다. 추가한 A13 테스트 22건은 모두 통과했다. 기존 Three.js 테스트에서 CommonJS 사용 중단 경고가 출력됐다.
- `npm run build`는 전체 검증 명령이 테스트에서 멈춘 뒤 별도로 실행했다. 종료 코드 0, Vite 출력은 `3176 modules transformed`였다.
- `git diff --check` 통과.

## 확인하지 못한 항목

로컬 Chromium 시작 시 샌드박스가 macOS Mach 포트 등록을 거부했다. 실제 브라우저 새로고침과 375px 가로 넘침, 스크린 리더의 음성 출력, 운영 Supabase 세션 및 서버 측 해시 저장은 확인하지 못했다. 접근성 검증은 Testing Library의 키보드 조작, 포커스, 접근 가능한 이름·설명, 상태·오류 역할을 대상으로 했다.

## Requests to orchestrator

`src/app/commerceRoutes.test.tsx`의 화면 제목 테스트는 모든 경로에서 먼저 가입해 회원 세션을 만든다. 따라서 `/signup`과 `/login`에서는 요구사항에 따라 홈으로 이동하고, 기존 테스트가 기다리는 인증 화면 제목은 나타나지 않는다. 해당 파일은 A13 수정 범위 밖이다. 두 인증 경로의 제목 검증은 게스트 세션으로 실행하고 보호 경로의 제목 검증은 회원 세션을 유지하도록 픽스처를 조정해 주세요.
