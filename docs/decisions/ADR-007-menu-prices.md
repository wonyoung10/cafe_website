# ADR-007 메뉴 판매가 표시

- 날짜: 2026-11-17
- 상태: 채택 (MN-06 변경)

## 배경
초기 기획은 과제 범위 제한으로 메뉴 가격을 제외했다. 사용자가 다른 카페를 참고해 가격을 넣어 달라고 요청했다.

## 결정
- `MenuItem.price`(원, 부가세 포함)를 추가하고 일반 카드·대표(lead) 카드 모두 온도 배지 오른쪽에 표시한다.
- HOT/ICE는 같은 가격, 100원 단위.
- 가격대는 동네 스페셜티 카페 기준: 2026년 스타벅스 아메리카노(톨) 4,700원·카페라떼 5,200원 수준과 비슷하거나 약간 위.
  - 커피 4,000~6,000원, 논커피 5,800~6,500원, 차 5,000~5,500원, 디저트 3,500~7,000원.
- 주문·결제·장바구니는 여전히 범위 밖.
