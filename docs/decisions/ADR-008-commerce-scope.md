# ADR-008 회원·구매·리뷰 추가와 Supabase

- 날짜: 2026-11-25
- 상태: 채택 (00·02 문서의 로그인·주문·결제·DB 제외 항목을 대체)

## 배경
사용자가 회원가입, 로그인, 장바구니, 상품 구매(모의 결제), 구매 후 리뷰를 요청했다. 처음에는 로컬 DB(브라우저 IndexedDB)로 정했다가, 리뷰를 다른 사람과 공유하기 위해 Supabase로 바꿨다.

## 검토
| 방식 | 공유 | Vercel 정적 배포 | 비고 |
|---|---|---|---|
| IndexedDB | 같은 브라우저만 | 동작 | 서버·계정 없음 |
| SQLite + 로컬 Node 서버 | 같은 PC·와이파이 | 동작 안 함 | 발표 때 서버 실행 |
| Supabase | 인터넷 전체 | 동작 | 사용자 계정·프로젝트 필요 |

## 결정
Supabase(Postgres + Auth + Storage). 소유권·구매 여부·가격은 DB의 RLS와 RPC에서 강제한다. 실제 결제는 연결하지 않고 결제 정보도 받지 않는다.

## 결과
- 무료 프로젝트는 사용이 적으면 일시정지될 수 있다. 발표 전에 접속해 확인한다.
- 아이디 로그인은 내부 이메일로 바꿔 처리하므로 비밀번호 찾기 메일은 제공하지 않는다.
- 운영에 쓰는 키는 공개 키뿐이다. 보안은 RLS가 책임지므로 정책은 PGlite 테스트로 고정한다.
- 온라인 결제 상태 `mock-paid`는 모의 값이다. 실제 결제 증빙이 아니다.
- 모의 결제 창의 흐름은 [ADR-011](ADR-011-realistic-payment.md)로 바뀌었다(2026-11-25).
